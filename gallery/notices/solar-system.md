# Grade 3 Sun, Earth and Moon assets

`sun.webp`, `mercury.webp`, `venus.webp`, `mars.webp`, `jupiter.webp`, `saturn.webp`, `uranus.webp`, and `neptune.webp` were derived from the corresponding files in [Sanghel/solar-system-3d](https://github.com/Sanghel/solar-system-3d). That repository records [Solar System Scope](https://www.solarsystemscope.com/textures/) as the upstream source and distributes the textures under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Each runtime texture was resized to a maximum width of 1024 px and converted to WebP. Earth and Moon intentionally reuse the existing Grade 4 runtime assets rather than creating duplicate copies. The Sanghel source repository is MIT licensed; only the listed texture files are used here.

The four `mentor/*.webp` illustrations were generated for this lesson with GPT Image 2. They contain no instructional text; the learner-facing caption and explanation are rendered by Lab029s so they remain accessible and localizable.
