# Three.js Lab Codex Plugin

Local Codex marketplace plugin for building and verifying interactive Three.js lab experiences.

## Install

From any checkout of this repo:

```bash
codex plugin marketplace add .
codex plugin add threejs-lab@threejs-lab-local
```

Start a new Codex thread after installing so the `$threejs-lab` skill is loaded.
